# Claude project entry point

Read `Plan.md` first. It is the single specification for the site: purpose,
stack, type, theme, the five-section page spec, content schemas, acceptance
criteria, and the build checklist. `HANDOFF.md`, `plan.md`, `ledger.md`, and
the old `docs/*.md` specs were folded into it and deleted on 2 Sep 2026.

The owner's design sketch is `docs/Website-Plan.pdf`.

For any mascot or animation task, read
`site/public/assets/animation/ANIMATION_ASSETS.md` next.

`site/public/assets/animation/` is the only canonical animation asset tree.
Do not restore or reference old GIFs, WebPs, extracted frame PNGs, chroma
boards, contact sheets, per-scene manifests, or paths under
`public/animations/oak-scenes/` or `public/sprites/`.

`site/dist/` is build output. It is never a source of assets.
