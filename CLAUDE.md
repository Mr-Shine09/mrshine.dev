# Claude project entry point

For any mascot or animation task, read
`site/public/assets/animation/ANIMATION_ASSETS.md` first.

`site/public/assets/animation/` is the only canonical animation asset tree.
Do not restore or reference old GIFs, WebPs, extracted frame PNGs, chroma
boards, contact sheets, per-scene manifests, or paths under
`public/animations/oak-scenes/`, `public/sprites/`, or
`design-handoff/oak-hero-v2/assets/`.

For the broader site architecture and acceptance criteria, read `HANDOFF.md`.
`plan.md` is historical and its single-page structure is superseded.
